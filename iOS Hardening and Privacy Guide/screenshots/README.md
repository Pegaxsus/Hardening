# Screenshots

Store screenshots used by the iOS Hardening and Privacy Guide in this folder.

## Conventions

- Prefer PNG for readable settings screens.
- Use descriptive lowercase names separated by hyphens, such as `passcode-settings-ios-<version>.png`.
- Use English device settings where possible to match the guide.
- Redact names, email addresses, phone numbers, device identifiers, location details, recovery keys, and other personal or sensitive information.
- State the iOS version in the accompanying documentation.

## Markdown usage

From the project README, reference screenshots with a relative path:

```markdown
![Description of the settings screen](screenshots/example.png)
```

The filename above is an example; no screenshots have been added yet.
