# iOS Hardening and Privacy Guide

Practical documentation in English on improving the security and privacy of iOS devices.

## Project status

Initial documentation structure. The sections below are planned topics; detailed instructions and screenshots will be added and verified against the relevant iOS version.

## Planned contents

1. Scope, supported iOS versions, and threat model
2. Software updates
3. Device passcode, Face ID, and Touch ID
4. Apple Account security and account recovery
5. Lock screen access and device theft protection
6. Application permissions and privacy settings
7. Network connectivity and secure browsing
8. Backups and data protection
9. Advanced protections and Lockdown Mode
10. Security checklist and verification

## Documentation conventions

- Write all documentation in English and Markdown.
- Record the iOS version used to verify each procedure.
- Include the settings path, expected result, and relevant usability tradeoffs.
- Reference official Apple documentation for technical claims.
- Remove personal information from screenshots before committing them.
